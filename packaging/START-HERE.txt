Speed Editor Customizer for Windows 10/11 (64-bit)

1. Right-click the downloaded ZIP and choose Extract All.
2. Keep the entire SpeedEditorCustomizer folder in a permanent location.
3. Double-click SpeedEditorCustomizer.exe to open the GUI.
4. Optional: double-click Create Desktop Shortcut.vbs to add a desktop shortcut.
   If your Windows policy disables scripts, right-click the EXE and use
   Show more options > Send to > Desktop (create shortcut).

Python, PowerShell, and administrator rights are not needed to run the app.
This version has no sign-in or cloud-sync service and does not connect to
the original developer's API. Use Settings > Local profiles to export/import
your mappings as local JSON files. OBS integration uses your configured host.
The GUI opens without a controller. Connect your Speed Editor by USB or
Bluetooth to use its buttons and dial.

Keep the _internal folder beside the EXE; it contains required dependencies.
To update: close the app, extract the new ZIP, and replace the old app folder.
Keep its location/name the same if you made a desktop shortcut.

Mappings are stored separately in:
  %LOCALAPPDATA%\SpeedEditorCustomizer\config.json
The previous valid save is kept as config.json.bak.
An existing config.json beside the EXE is imported on first use only when
there is no configuration in the user-data folder. The original is preserved.
To move mappings from another installation, use the GUI's JSON import/export.

WINDOWS CONTROLS
Open Windows & profiles to manage local profiles and optional auto switching.
Click a controller button for Tap / Double tap / Long press mappings.
Click the dial for shortcut, scroll, zoom, volume and brightness assignments.
Use the tray icon to pause, switch profiles, release keys, cancel macros or quit.
Closing the main window keeps the app in the tray by default.
No account, paid API, subscription or cloud service is used by these features.
A Defender detection still needs investigation; do not disable protection.

JOG / SHUTTLE / SCROLL AND LEDs
Click the dial picture. Set Turn controls to Editing transport and Save.
Focus the timeline/viewer in Resolve. JOG steps frames; SCRL steps faster.
SHTL establishes centre at the current dial position: turn either way for
reverse/forward playback with speed bands (default 1x/2x/4x/8x). Return to
centre to stop. STOP/PLAY toggles playback; press SHTL again to re-centre.
After STOP, return to neutral before shuttling again. The dial has no spring.
Adjust units/frame, scroll steps, neutral zone and speed bands in the GUI.
Mode LEDs and supported mapped-button LEDs follow the customiser state.
Switch LED feedback off under Windows & profiles if preferred.
The four transport buttons are reserved only while Editing transport is active.
This uses configurable keyboard shortcuts, not native Resolve integration.
Stop playback before changing apps: if Resolve loses focus, the stop command
waits until its window regains focus, and playback may continue meanwhile.
Hardware feel and simultaneous Resolve control still need device testing.
